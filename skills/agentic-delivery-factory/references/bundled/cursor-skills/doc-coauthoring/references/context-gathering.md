# Context gathering — doc co-authoring

Ask or infer answers before proposing structure.

## Minimum questions

1. **Audience**: Who reads this node and what decision do they make?
2. **Scope**: What is in / out for this version?
3. **Success**: How will we know the document succeeded?
4. **Constraints**: Time, tech, policy, dependencies?
5. **Catalog type**: Which Document Type Catalog row is the SSOT template?

## Output

A short bullet list the user can confirm in one reply:

```markdown
- Audience: …
- In scope: …
- Out of scope: …
- Success: …
- Catalog type: …
- Open questions: …
```

Do not draft the full node until the user confirms or explicitly asks to proceed with stated assumptions.
